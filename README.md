# FreelanceFlow AI — Smart Scope & Instant PayPal Checkout

FreelanceFlow AI bridges the gap between freelance project estimation and immediate client commitment. It turns conversational project briefs into structured, milestone-based deliverables with an automated PayPal deposit checkout flow.

## 🚀 Live Demo
- **Live Application:** [https://joyobaga.github.io/ai-commerce-assistant/](https://joyobaga.github.io/ai-commerce-assistant/)
- **Demo Video:** (https://youtu.be/jS0v4HoXEps)

## 💡 The Problem
Freelancers lose billable hours writing custom proposals and often face scope creep or delayed upfront deposits. Clients often abandon lengthy contract documents before initiating work.

## ⚙️ How It Works
1. **Intelligent Scope Breakdown:** The client brief is parsed into structured milestones with suggested pricing.
2. **Upfront Deposit Lock-In:** FreelanceFlow dynamically mounts a PayPal Smart Button for a 50% deposit based on calculated scope.
3. **Instant Confirmation:** Upon payment capture via the PayPal Orders SDK, the project status shifts to Active with an automated audit trail (Transaction ID, payer details).

## 🛠️ Tech Stack & Integrations
- **Frontend:** Responsive HTML5 / Modern CSS / Vanilla JavaScript (GitHub Pages deployment)
- **Payments:** PayPal JavaScript SDK (v5/v6) Orders API (`createOrder` and `capture` lifecycle)
- **AI Task Parser:** Client-side natural language scoping engine
